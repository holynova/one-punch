第一阶段 纯浏览器运行

GITHUB 网页 → 本地 SHELL 脚本

把浏览器里能看到的 GitHub 仓库，变成一份本地 setup.sh。

把一段脚本粘贴到 DevTools 控制台，Repo2Script 会遍历当前仓库目录，抓取支持的文本文件，生成一份自包含的恢复脚本。

下载脚本文件 ↓ 查看仓库 ↗ 看看流程 ↓

不用 API Token，不用 clone，不经过第三方服务。

repo2script.paste.js v0.1.0

03›paste dist/repo2script.paste.js

01 / 流程

从页面到文件，一条看得见的路。

  1. 01

    打开

    从浏览器能打开的仓库根目录开始。

  2. 02

    粘贴

    在 GitHub 页面的 DevTools 控制台里运行这段脚本。

  3. 03

    恢复

    复制 setup.sh，把文件写回本地文件夹。

02 / 边界

能力小，边界清。

Repo2Script 只处理可见的仓库目录和支持的 UTF-8 文本。不支持的文件会在结果浮层和生成的脚本注释里说明。
